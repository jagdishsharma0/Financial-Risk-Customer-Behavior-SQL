# 🏦 Financial Risk & Customer Behavior Analytics (SQL)

## 📘 Overview

This project analyzes a **banking transaction dataset** to evaluate **customer financial behavior**, **revenue concentration**, and **fraud risk exposure** using **Microsoft SQL Server**.

The objective is to transform raw transactional data into a structured analytical system capable of delivering **KPI-driven business insights**, **risk detection indicators**, and **performance monitoring metrics**.

This project demonstrates how **SQL can be leveraged as a full-scale analytical engine**, not just a querying tool, to build a **complete financial intelligence framework**.

---

## 🎯 Objectives

- Normalize raw transactional data into **structured relational tables**
- Design scalable **customer and transaction data models**
- Engineer reusable **KPI reporting views**
- Identify **high-revenue** and **high-risk customers**
- Measure **fraud exposure** and **transaction success rates**
- Analyze **revenue concentration** and **growth trends**
- Apply **advanced SQL techniques** for business analytics

---

## 🧰 Tools & Technologies Used

- **Microsoft SQL Server**
- **SQL Server Management Studio (SSMS)**
- **Relational Data Modeling**
- **Primary & Foreign Key Constraints**
- **Non-Clustered Indexing**
- **CTEs (Common Table Expressions)**
- **Window Functions (RANK, DENSE_RANK, LAG)**
- **KPI View Engineering**
- **Stored Procedures**

---

## 🏗 Steps Performed

### 1️⃣ **Data Structuring & Modeling**
- Split raw dataset into:
  - `Bank_Customers` (**dimension table**)
  - `Bank_Transactions` (**fact table**)
- Applied **relational integrity constraints**
- Created a **consolidated analytical table** for reporting efficiency

---

### 2️⃣ **Performance Optimization**
- Implemented **non-clustered indexes**
- Designed optimized query structure for **aggregation-heavy analysis**

---

### 3️⃣ **KPI Engineering**
Created reusable **executive-level views** for:
- **Total Customers**
- **Transaction Volume**
- **Average Transaction Value**
- **Fraud Rate Percentage**
- **Revenue Monitoring Metrics**

---

### 4️⃣ **Core Financial Analytics**
- Customer distribution analysis
- Income segmentation modeling
- **Top revenue contributor identification**
- Payment method usage trends
- **Transaction success rate analysis**
- Fraud exposure by demographic segment

---

### 5️⃣ **Advanced Analytical Insights**
- **Revenue contribution analysis (Top 20% customers)**
- **Spending-to-income risk detection**
- High-risk customer identification
- **Month-over-month revenue growth tracking**
- Window-function-based ranking analysis

---

## 📈 Key Business Insights

- Identified **revenue concentration dependency** on top customers
- Detected customers spending beyond **safe income thresholds**
- Quantified fraud exposure across **payment methods**
- Measured overall **transaction success rates**
- Evaluated **financial growth patterns** over time

---

## 💼 Business Value

This framework enables financial institutions to:

- Monitor **fraud risk systematically**
- Detect **high-risk financial behavior early**
- Understand **customer value distribution**
- Reduce **revenue dependency risk**
- Support **data-driven decision-making**

The project highlights how **SQL transforms raw financial transactions into structured business intelligence**.
